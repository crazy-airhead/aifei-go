更新记录 ​

Aifei-Go 演进时间线，按版本倒序。本仓库为 Go workspace 多模块架构，所有库模块锁步发布（scripts/tag.sh 统一打 <mod>/vX.Y.Z tag），下文版本号即锁步版本。

v1.2.0 · 2026-10-11 ​

全仓锁步 v1.2.0（上一轮 v1.1.0 仅覆盖 5 个 AI 模块、存量模块停在 v1.0.3，本次归一）：

  • mcp、sandbox、ai/flow、ai/harness、ai/loop 五个模块首次纳入锁步发布，可独立 go get
  • plugins/ai：talent lucene → bleve 更名（Bleve + gse 纯 Go 中文分词，以实现技术命名）
  • plugins/ai/ragloader：docx / pptx / xlsx / pdf 重格式处理统一收敛到 markitdown
  • 发布工具 scripts/tag.sh 锁步清单补齐 10 个 AI 专项模块与 8 个测试模块

v1.1.0 · 2026-10 ​

AI 能力专项（solon-ai 迁移，P0~P7）全量落地。 从聊天核心到智能体、MCP、RAG、能力包、编码代理容器，AI 全家桶一次到位：

领域内容
聊天核心消息 / 内容块、事件模型与聚合器、模型执行管线（call + autoToolCall）、流式三通道（Stream / StreamChan / CallStream）、方言矩阵（OpenAI / Anthropic / Gemini（含 Interactions API）/ Ollama / DashScope / OpenAI Responses）、embedding、rerank、generate、router 四策略、FileSession 原子写、ui/aisdk 流协议适配、agui 事件族
智能体Simple / ReAct 两类 Agent 与拦截器；Team 五协议：A2A / ContractNet / Blackboard / MarketBased / None；ai/flow AI 流编排 12 组件
MCP协议层（schema / types / version / session）、客户端门面（stdio 传输 + 心跳重连）、服务端门面（stdio / 旧式 SSE / streamable HTTP）、ai/mcp 桥、plugins/ai 配置装配插件
RAGSPI 与内置实现、切分器四件 + Pipeline + 检索辅助、搜索即仓储（Tavily / Bocha / 百度）、ragloader 7 件（docx / pptx / xlsx / pdf 重格式统一经 markitdown）、ragrepo 11 个向量仓储后端（ES / pgvector / Redis / SQL / Chroma / DashVector / OpenSearch / Weaviate / 腾讯 vectordb 等）
能力包26 件 talent：零依赖批（file / sys / diff / web（含 crawler，JINA / Firecrawl 双驱动）/ generation / social / mail / mount / memory / code / data）+ 依赖批（text2sql / bleve（Bleve + gse 纯 Go 中文分词）/ gateway / pdf / cli / lsp）
编码代理ai/harness 编码代理容器 + 上下文压缩拦截器；ai/loop 持久循环引擎（agent / flow / harness 三集成桥）；sandbox 命令沙箱四后端（darwin Seatbelt / linux bwrap / 代理服务器三件 / windows WFP）

配套新增 AI 能力六篇使用指南与 docs/arch/ai/ 八篇契约设计。专项中途锁步点为 v1.0.3（P4 收口），收口后新增 AI 模块以 v1.1.0 发布。
