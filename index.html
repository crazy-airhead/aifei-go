Just Service

方法名即路由：Register() 按命名约定（动词前缀 + 默认动作）把 Service 方法直接映射为 RESTful 端点——免写 Controller 层，Dao 弱化为可选薄层。

🧊

零外部依赖核心

核心库与独立框架（aifei/enjoy/db/json/log/nami/dami）仅用 Go 标准库；插件按需引入第三方库。

🧩

模块化设计

Go workspace 多模块架构，各模块可独立 go get、按需组合，不拉入多余依赖。

✨

Enjoy 模板引擎

自研模板语言（~2800 行）：表达式、条件、循环、宏定义、空安全（?? / ?.）、静态访问。

🗄️

Active Record ORM

Row + Dao 链式操作与变更追踪；Enjoy SQL 模板引擎（#where / #and + 18 种操作符，条件为空自动省略）。

⚙️

代码生成器

从数据库 Schema 自动生成类型安全的 CRUD 代码（base / model / dao / service，每表一个独立包）。

🌲

基数树路由 + AOP

每 HTTP 方法一棵 radix 树，支持参数与通配符；Handler 包装链 + 方法级 Interceptor 拦截器。

🔌

插件生态

两级缓存、Kafka、Nacos、S3 兼容存储、Elasticsearch、XXL-JOB、Swagger、数据隔离、流程编排等可选集成。

基于 Apache-2.0 许可发布
