# ISSUE-0016 — db 细节补强（Batch / TypeConverter / 复合主键 / 事务返回值 / 杂项）

> **编号**：0016　**状态**：🔴 未处理　**严重程度**：💡 体验
> **发现日期**：2026-07-16　**相关任务**：db 模块（对照 `docs/java-go-comparison.md` §2.3）

## 问题描述

多项中低优先级补强，合并登记为 checklist，便于逐项收敛。

## 期望行为（应有功能清单）

- [ ] **Batch**：补 `batchSize` / `commitOnBatchSize`（分块提交）、`getGeneratedKeys`（批量回填自增主键）、`UpdateCounts`、异构批分组 `BatchGroup`（多表/混列批）。当前 `db/batch.go` 假定同构，读 `rows[0]` 取字段。
- [ ] **TypeConverter**：补 `toBigDecimal`（金融痛点）、`toBigInteger` / `toNumber` / `toShort` / `toByte` / `toFloat`（当前仅 6 个）。
- [ ] **复合主键**：Java `findByCompositeId` 任意列数；Go 固定 2 列版。
- [ ] **事务返回值**：Java `transaction(Atom<R>)` 返回泛型业务结果、可成功路径主动回滚；Go `Transaction(fn func() error) error` 只返回 error，`server.TxInterceptor` 硬编码 `Code()!=0` 回滚。
- [ ] **Kv**：有序 fluent 参数 Map（Java `util/Kv.java`）；Go 用裸 `map` 替代。
- [ ] **Row 小缺口**：`setOrPut`、`data()` 批量读写、`get(field, converter)` 函数式转换器。
- [ ] **SqlKit 小缺口**：`#orderBy` 未 trim 字段/方向、operator 全小写别名未注册、`ParaDirective` 全局开关 `setCheckParaAssigned`。
- [ ] **错误回调/默认值**：`findOne` 自定义错误消息回调、`queryField(defaultValue)` 默认值重载。

## 影响范围

批量写入性能与正确性、金融数值精度、多主键表、事务业务结果回传、参数人体工学。

## 相关文件 / 符号

- `db/batch.go`、`db/type_converter.go`、`db/transaction.go`、`db/dao.go`、`db/row.go`、`db/sql/{operator,orderby_directive,para_directive}.go`
- 对照 Java：`aifei-db/{core/Batch.java,core/TypeConverter.java,util/Kv.java,core/Dao.java,sql/*}`

## 建议方案

按 checklist 逐项补齐；优先 Batch 主键回填与 TypeConverter 的 `toBigDecimal`。
