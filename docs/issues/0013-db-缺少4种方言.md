# ISSUE-0013 — db 缺少 Oracle / SqlServer / H2 / Informix 方言

> **编号**：0013　**状态**：🔴 未处理　**严重程度**：⚠️ 一般
> **发现日期**：2026-07-16　**相关任务**：db 模块（对照 `docs/java-go-comparison.md` §2.2 / §2.4）

## 问题描述

Java 提供 8 种数据库方言；Go `db/dialect.go` 仅实现 MySQL / PostgreSQL / SQLite 三种，缺 Oracle / SqlServer / H2 / Informix，对应数据库的分页 SQL、主键回填、引号风格均无法生成。

## 期望行为（应有功能清单）

- [ ] `OracleDialect` — `rownum` 三层子查询分页、`.nextval` 序列、`getGeneratedKeys`
- [ ] `SqlServerDialect` — `ROW_NUMBER() OVER` / `OFFSET FETCH` 分页、`[ ]` 引号
- [ ] `H2Dialect` — Oracle 风格 `rownum`
- [ ] `InformixDialect` — `SKIP N FIRST M` 分页、空格填充引号

并在 `NewDialect` 的 driver 识别中注册。

## 实际行为（Go 现状）

`db/dialect.go` 的 `NewDialect` 仅识别 `mysql` / `postgres` / `pgx` / `sqlite` / `sqlite3`。

## 影响范围

使用 Oracle / SQL Server / H2 / Informix 的部署；分页查询与自增主键回填。

## 相关文件 / 符号

- `db/dialect.go` — `NewDialect`、`MySQLDialect`/`PostgresDialect`/`SQLiteDialect`
- 对照 Java：`aifei-db/dialect/{Oracle,SqlServer,H2,Informix}Dialect.java`

## 建议方案

按 Java 实现补齐 4 个 `Dialect`（分页 SQL 各异，注意 Oracle 三层子查询、SQL Server 的 OFFSET FETCH）；在 `NewDialect` 注册 driver 名。
